# portfolio.junshuolu.com

Single-file portfolio drawn as an engineering sheet. No frameworks, no build step.

- index.html: the whole site (HTML + CSS + JS)
- fonts/: self-hosted woff2 (Archivo variable, DM Mono, a 4-glyph Noto Serif SC subset for the seal)
- media/: optional project posters and loop videos (see media/README.txt)
- resume.pdf: the PDF the Résumé button opens

Concept, spec and acceptance by Junshuo Lu; code generated with Claude Code and verified with jsdom smoke tests and the Khronos GLSL validator.
